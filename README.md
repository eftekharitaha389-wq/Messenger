# پیام‌رسان خصوصی (نسخه پروتوتایپ)

## قابلیت‌ها
- ثبت‌نام و ورود با شماره موبایل + رمز
- فقط چت خصوصی (پیوی) بین دو نفر
- ارسال متن، فایل و ویس
- پنل ادمین: فقط ادمین همه چت‌ها را می‌بیند
- کاربران عادی فقط چت خودشان را می‌بینند

(هر رمزی که خواستید)

بعد از ورود، دکمه 👑 در بالای صفحه ظاهر می‌شود.

## نکات مهم
- این نسخه برای یادگیری و تست محلی است.
- داده‌ها در فایل  ذخیره می‌شوند.
- فایل‌ها در پوشه  قرار می‌گیرند.
- برای استفاده واقعی باید:
  - سیستم OTP واقعی (پیامک) اضافه شود
  - دیتابیس واقعی (MongoDB یا PostgreSQL) استفاده شود
  - HTTPS و امنیت بیشتری اعمال شود
  - سرور روی هاست واقعی قرار گیرد
