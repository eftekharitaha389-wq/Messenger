# دوستیابی (نسخه ۲)

اپلیکیشن چت خصوصی شبیه دوستیابی.

## قابلیت‌ها
- ثبت‌نام و ورود با شماره موبایل + رمز
- نمایش **همه پروفایل‌ها و نام‌ها** به کاربران (مثل دوستیابی)
- **شماره موبایل کاربران فقط برای مالک (ادمین) قابل مشاهده است**
- چت خصوصی (پی‌وی) بین دو نفر بدون نیاز به جستجو
- ارسال متن، عکس، ویدیو، ویس و آهنگ
- پنل ادمین: مالک همه چت‌ها را می‌بیند و از پیام‌ها باخبر می‌شود
- کاربران عادی فقط چت خودشان را می‌بینند و شماره‌ای نمی‌بینند

## نصب و اجرا

```bash
cd dostyab
npm install
node server.js
```

سپس مرورگر را باز کنید: http://localhost:3000

**شماره:** `09940355222`  
(هر رمزی که خواستید)

بعد از ورود، دکمه 👑 در بالای صفحه ظاهر می‌شود.

## نکات مهم
- این نسخه برای تست محلی است.
- داده‌ها در فایل `data.json` ذخیره می‌شوند.
- فایل‌ها در پوشه `uploads` قرار می‌گیرند.
- برای استفاده واقعی:
  - سیستم OTP واقعی (پیامک) اضافه شود
  - دیتابیس واقعی استفاده شود
  - HTTPS و امنیت بیشتری اعمال شود

## تغییرات نسبت به نسخه قبلی
- نام سایت به **دوستیابی** تغییر کرد
- شماره‌ها از دید کاربران عادی کاملاً مخفی شد
- لیست همه افراد روی صفحه نمایش داده می‌شود (بدون نیاز به سرچ اجباری)
- پشتیبانی بهتر از عکس، ویدیو و موسیقی
- ادمین همچنان به همه چت‌ها دسترسی دارد و شماره‌ها را می‌بیند
